# HR Data Integration & Analytics | Talend ETL Pipeline

## Project Overview

This project focuses on developing an end-to-end **ETL (Extract, Transform, Load) solution** for Human Resources data using **Talend, SQL, MySQL, and Power BI**.

The goal is to integrate, transform, and analyze HR data to support workforce management and data-driven decision-making.

The project covers data integration, data quality, database management, and business intelligence.

## Objectives

- Design and implement ETL pipelines for HR data.
- Extract and integrate data from different sources.
- Clean, validate, and transform employee information.
- Automate data processing and database loading.
- Organize HR data for reporting and analysis.
- Develop dashboards to monitor HR performance.
- Support HR decision-making through data analytics.

## Dataset

The project uses the **IBM HR Analytics Employee Attrition & Performance Dataset**.

The dataset contains information related to employee demographics, job characteristics, compensation, satisfaction, and attrition.

It provides a foundation for exploring HR data integration and analytics.

## Project Architecture

The proposed architecture follows an ETL workflow:

```text
        HR Data Sources
              |
              v
        Data Extraction
              |
              v
       Data Transformation
              |
              v
     Data Quality Validation
              |
              v
         MySQL Database
              |
              v
       Power BI Analytics
```
